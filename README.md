# 손가락 운동회 🐾 (이쪽저쪽 · 세 줄 쌓기)

손가락으로 하는 짧은 반응 게임 모음입니다. 로비에서는 `/sort/`(이쪽저쪽)와 `/stack/`(세 줄 쌓기) 두 주소로 따로 열립니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

## 조작
### 이쪽저쪽
- `←` `→` 키(폰은 화면 왼쪽/오른쪽 탭)로 가운데 줄 맨 앞 동물이 속한 편을 고릅니다.

### 세 줄 쌓기
- `←` `↓` `→`(또는 `A` `S` `D`, 폰은 화면 버튼)로 내려오는 블록을 세 줄 중 하나에 쌓습니다.

## 규칙
- 이쪽저쪽: 맞게 고르면 다음 동물, 틀리면 1초 감점. 맞출수록 콤보가 쌓입니다. 기록 키 `undonghoe_sort`.
- 세 줄 쌓기: 맨 위 같은 색 3개가 모이면 사라지고 🌈 는 아래 색으로 변합니다. 기록 키 `undonghoe_stack`.

## 구조
- `game.js` 에 종목 목록(`sort`, `stack`)과 화면·입력, `logic.js` 두 게임의 규칙(`LOGIC_UNDONGHOE`).
- 규칙은 DOM 없는 `logic.js`, 시험은 `node --test` (`test/logic.test.js`).
